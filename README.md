# Farm Home

Farm Home is a signed-in farm log. After email and password sign-in, you can create and list records, resources, and reference data stored in Cloud Firestore.

Supported platforms are Android, web, and Windows. Linux is scaffolded, but Firebase is not configured for it.

This project targets Flutter 3.50.1 (Dart 3.14).
